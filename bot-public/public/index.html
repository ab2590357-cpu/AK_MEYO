Do I need the owner's password or access code?+

No owner dashboard password is needed to use the public pairing page while public access is enabled. The owner can pause new pairing.

Which linking option should I choose?+

Use QR if you can open this page on another screen. Choose phone code if your WhatsApp app supports that linking method.

Can anyone see my WhatsApp chats?+

Only link accounts you control. Treat the linked session as sensitive: it can access WhatsApp data available to that device. Never share the QR, device code, or management key.

What if the owner pauses pairing?+

The website will stay online with a clear paused message. Existing linked WhatsApp sessions are not automatically reset by the public pairing switch.
