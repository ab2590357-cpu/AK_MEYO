Run A-X-HK the right way

The WhatsApp bot needs a persistent Node.js process. Use VPS, Docker, Railway, Render with persistent storage, or another always-on Node host. Vercel is only for the optional static mini-site.

VPS + PM2

Best control and reliability. Session files remain on your server disk.

Recommended

Docker

Use the included Dockerfile and mount persistent volumes for SESSION_DIR, MULTI_SESSION_DIR and DATA_DIR.

Production

Railway

Works as a persistent Node service. Attach persistent storage before pairing.

Cloud

Render

Works as a web service, but session survival requires persistent disk/storage configuration.

Cloud

Vercel Mini Site

Use only the included mini-site/ as a static branded landing page, not the long-running WhatsApp socket.

Static only

Separate Pair Site

Optional secure proxy included under pair-site/. Main bot already has a full protected /pair page.

Required persistent folders
